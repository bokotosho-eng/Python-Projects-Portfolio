# Python CGPA Calculator

## 📊 Overview
This project is a Python script that calculates a student's cumulative GPA (CGPA) based on:
- Previous GPA and credit hours
- Current semester GPA and credit hours
- New course entries with credit hours and letter grades

## ⚙️ How to Run
1. Clone or download the repository.
2. Save the file as `my_cgpa_calculator.py`.
3. Run in terminal:
4. Enter the required inputs when prompted.

## 🏅 Features
- Uses `input()` to collect user data interactively.
- Performs weighted GPA calculation using:
- Allows multiple course entries until the user chooses to stop.
- Prints a formatted cumulative academic report.

### Input
Enter your name: Bayan
Enter your cumulative GPA before this semester: 3.27
